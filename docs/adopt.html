Adopting ERI — A Guide for Teams

Evaluate, plan, and ship interactive Agent output in your organization.

Is ERI Right for You?

ERI fits if you:

  • Have an existing web application and want it embedded in any Agent conversation
  • Are a third-party service provider who wants your app to work with ChatGPT, Claude, Gemini — all of them
  • Want to ship today without waiting for platform SDKs or approval
  • Prefer controlling your own embed experience rather than relying on platform renderers

ERI does not fit if:

  • You're building a platform that renders its own UI components (use A2UI instead)
  • You're investing in the MCP ecosystem exclusively (use MCP Apps instead)
  • You need real-time bidirectional sync (ERI is snapshot-based)

Quick Validation — 5 Minutes

Before committing to anything, validate ERI with this test:

  1. Open the live demo — see an interactive calculator embedded by an Agent
  2. Edit the numbers in the calculator — results update instantly, no round trip
  3. Show your team: "This is what our app could look like inside ChatGPT"

If that sparks interest, proceed to the checklist below.

Adoption Checklist

Phase 1: Pilot (1 day)

  • Pick one existing web app to embed
  • Create a stripped-down /embed route (~40 lines)
    • Reads initial state from URL hash or query params
    • Self-contained — no dependency on host page
    • Served over HTTPS
  • Write a skill.md following the spec
  • Test with your Agent platform — confirm iframes render correctly

Phase 2: Integration (1 week)

  • Ensure sandbox="allow-scripts allow-same-origin" is set on iframe rendering
  • Test responsive behavior at different embed widths
  • Verify no document.cookie, window.top, or window.opener usage in embed page
  • Handle edge cases: invalid URL params, slow networks, empty state

Phase 3: Polish (optional)

  • Add theme adaptation (light/dark) via URL param or prefers-color-scheme
  • Implement postMessage for Level 2 bidirectional communication
  • Monitor embed page performance and load time

Common Objections

"Isn't iframe outdated?"

No — every major Agent platform (ChatGPT, Claude, Gemini) renders iframes today. iframe is how the web embeds things. It works.

"What about security?"

Agent platforms sandbox iframes. Your embed page runs in a restricted context. Follow the security guidelines and you're fine.

"MCP Apps will replace this, right?"

MCP Apps require platform integration — your app only works on MCP-enabled platforms. ERI works on every platform because it's just a URL. As a third-party provider, ERI gives you the broadest reach with the least effort.

"What if our platform doesn't support iframes?"

ERI falls back to plain text output — the Agent still provides value via text. Most major platforms (ChatGPT, Claude, Gemini) render iframes today, so this is rarely an issue.
